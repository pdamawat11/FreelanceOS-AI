# FreelanceOS-AI

A full-stack AI-powered freelancer management platform that helps freelancers organize projects, manage tasks, track progress, and improve productivity.

## Features

- 🔐 JWT Authentication
- 📁 Project Management (CRUD)
- ✅ Task Management (CRUD)
- 📊 Dashboard with project & task statistics
- 🗄️ PostgreSQL Database
- ⚡ Prisma ORM
- 🌐 RESTful APIs
- 🤖 AI features (Coming Soon)
- 🎨 React Frontend (Coming Soon)

## Tech Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Bcrypt

### Frontend (In Progress)
- React
- Tailwind CSS

## Getting Started

```bash
git clone https://github.com/pdamawat11/FreelanceOS-AI.git
cd FreelanceOS-AI/backend
npm install
npm run dev
```
